# Triage labels

| Canonical role | Local status |
| --- | --- |
| `needs-triage` | `needs-triage` |
| `needs-info` | `needs-info` |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `resolved` | `resolved` |
| `wontfix` | `wontfix` |

`resolved` is a local terminal state. Resolved tickets are not actionable or
agent-selectable and are distinct from `wontfix`.

Use the local status in a ticket's `Status:` field whenever an engineering
skill refers to the corresponding canonical role.
