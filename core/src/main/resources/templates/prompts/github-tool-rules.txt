  view  → fetch a specific repo or file. Target MUST be 'owner/repo'.
          ✅ use 'repo' for action, 'view' for command, and 'owner/repo' for target.
          ✅ use 'file' for action, 'view' for command, 'owner/repo' for target, and the file path.
  list  → list ALL repos for an owner. Target MUST be ONLY the owner name.
          ✅ use 'repo' for action, 'list' for command, and the owner name for target.
          ❌ using 'owner/repo' for target with 'list' is FORBIDDEN.
  gist  → list gists for a user. Use 'gist' for action, 'list' for command, and the username for target.
          ✅ user asks 'list gists for owner' → action='gist', command='list', target='owner'
          ✅ user asks 'my gists' or 'my gist list' → action='gist', command='list' (omit target for authenticated user)
  When you need a specific repo, ALWAYS use 'view', not 'list'.
  If the repository or file is not accessible (missing token, private repo, 404), STOP and report what you found from public context only.
  Do NOT retry a tool call that already failed with the same parameters.

  'details', 'info' from the target value.
