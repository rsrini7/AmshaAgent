# Security Policy

Amsha Agent is in active development. No supported-release window or response-time service level is currently published.

## Report a vulnerability

Do not post vulnerability details, exploit steps, credentials, private user data, or raw provider payloads in a public issue or pull request.

Use GitHub's private vulnerability reporting feature for this repository when it is available. If private reporting is unavailable, contact the repository maintainer privately through [GitHub](https://github.com/rsrini7/AmshaAgent) before sharing details publicly.

Please include the affected commit or release, the potential impact, and concise reproduction steps. Use synthetic data and redact secrets from any evidence.

## Supported versions

The project is in active development. Include the affected commit or release in your report; fixes and backports are handled by maintainers on a case-by-case basis.
