## **P4 – Architecture & Operational Readiness**

*   **AO-1: Wire Generated OpenAPI Types into UI Components:** Migrate component imports from hand-written `types.ts` to generated types in `src/api/generated/`.
*   **AO-2: Add Pagination on Query Endpoints:** Add `?page=&size=` or cursor-based pagination to endpoints like `getPendingApprovals()`.
*   **AO-3: Add Rate Limiting on REST Endpoints:** Add `@RateLimit(value=10, window=60)` on mutation endpoints to prevent quota exhaustion.
*   **AO-4: Add MDC Correlation ID Propagation:** Use JAX-RS filters to set `MDC.put("requestId", UUID)` for request correlation across logs.
*   **AO-5: Add Idempotency on Approval Endpoints:** Implement `X-Idempotency-Key` header support in `HitlService.java` to prevent double-approvals.
*   **AO-6: Fix WebSocket Concurrent State Races:** Consolidate four non-atomic concurrent maps into a single `ConcurrentHashMap` in `WebChatEndpoint.java`.
*   **AO-7: Add API Versioning:** Implement `/api/v1/` prefixing for all unversioned endpoints.
*   **AO-8: Split MessageContext into Domain + Transport:** Separate transport details (e.g., `chatId`) from domain logic (e.g., `agentRole`) into `DomainContext` and `TransportContext`.
