## **P1 – Quick Wins (< 1 hour each) [DONE]**

Refer #Architecture_Invariants.md

Also, whatever exception tracking should be used import org.apache.commons.lang3.exception.ExceptionUtils; to avoid large stacktrace of logs. no need to install externally.

### **QW-1: Uncomment Prometheus Alert Rules [DONE]**
* **File:** `prometheus.yml`
* **Issue:** 4 alert rules (`AgentLoopHighFailureRate`, `ToolTimeoutDetected`, `LLMRateLimitSpike`, `HITLAutoDenyBurst`) are commented out.
* **Fix:** Uncomment or move to dedicated `alert_rules.yml`. Wire into Prometheus config.
* **Invariant:** §3.1

### **QW-2: Add Logging to Empty Catch Blocks (6 files) [DONE]**
* **Files:** `CronSchemaEnforcer.java` (6 locations), `PlaywrightBrowserInstaller.java` (3), `AppBootstrap.java` (5), `McpClientService.java` (2), `PlaywrightPageRunner.java` (3), `AgentLoop.java` (2)
* **Issue:** ~21 empty or comment-only catch blocks silently swallow errors.
* **Fix:** Replace with `log.debug("...", e)` or `log.warn("...", e)` as appropriate. Resource-cleanup catches get `debug`; init/transport failures get `warn`.

### **QW-3: Externalize PlaywrightPageRunner Magic Numbers [DONE]**
* **File:** `arcclaw-tool-playwright/.../PlaywrightPageRunner.java`
* **Issue:** `MAX_SCREENSHOT_BYTES = 1_048_576`, `NETWORK_IDLE_RATIO = 0.30`, `RUN_FUTURE_BUFFER_MS = 5_000L` are hardcoded.
* **Fix:** Move to `@ConfigProperty` with current values as defaults.

### **QW-4: Externalize Telegram Max Message Length [DONE]**
* **File:** `arcclaw-channel-telegram/.../TelegramChannelSender.java`
* **Issue:** `TELEGRAM_MAX_LENGTH = 4096` hardcoded.
* **Fix:** `@ConfigProperty(name = "arcclaw.channel.telegram.max-length", defaultValue = "4096")`.

### **QW-5: Externalize JSON Salvage Max Lines [DONE]**
* **File:** `arcclaw-core/.../util/TextPatternUtils.java`
* **Issue:** `JSON_SALVAGE_MAX_LINES = 20` hardcoded.
* **Fix:** `@ConfigProperty` with default `20`.

### **QW-6: Replace Thread.sleep in AgentCronScheduler [DONE]**
* **File:** `arcclaw-app/.../AgentCronScheduler.java:111`
* **Issue:** `Thread.sleep(5000)` – startup delay not configurable.
* **Fix:** `@ConfigProperty(name = "arcclaw.cron.startup-delay-ms", defaultValue = "5000")`.

### **QW-7: Externalize EngineStepHandler Rate-Limit Retry Sleep [DONE]**
* **File:** `arcclaw-core/.../agent/loop/EngineStepHandler.java:380`
* **Issue:** `Thread.sleep(retryAfterSeconds * 1000L)` – blocking a virtual thread.
* **Fix:** Consider `Uni.createFrom().voidItem().onItem().delayIt().by(Duration.ofSeconds(retryAfterSeconds))` or at minimum externalize max retry-after cap.

### **QW-8: Complete @ToolMetadata Migration for Base Roles [DONE]**
* **File:** `arcclaw-core/.../agent/AgentRoleEnum.java`
* **Issue:** `AgentRoleEnum.DEFINITIONS` still has hardcoded `Set.of(ToolCapability....)` per role. Annotation pipeline adds supplemental grants on top.
* **Fix:** Migrate base capability-to-role mappings to `@ToolMetadata` annotations on built-in tools.

---

### **QW-9: Clarify Reflex vs Command Terminology [DONE]**
* **Files:** Several `*Reflex.java` Javadoc comments mix "command" terminology (e.g., `SkillReflex.java` says "Handles the `/skills` command").
* **Fix:** Standardize all Javadoc to "reflex" terminology.

### **QW-10: Add @Size Validation on Chat DTOs [DONE]**
* **Files:** `ChatRequest.java`, `CreateSessionRequest.java`, other DTOs
* **Issue:** Only `RunAgentRequest` has `@NotBlank` / `@Min`. No `@Size` limits on message content – potential for oversized payloads.
* **Fix:** Add `@Size(max = 100000)` on message/goal fields, `@Pattern` for role enum validation.

### **QW-11: Standardize REST Error Response Format [DONE]**
* **Files:** `HitlResource.java`, `ChatStreamResource.java`, `AgentStatusResource.java`, `SkillResource.java`, `McpConnectResource.java`, `OnboardingResource.java`
* **Issue:** Error response structures vary across endpoints – some return plain text, some return JSON with different shapes.
* **Fix:** Create `ArcClawErrorResponse` record, use consistent JAX-RS `ExceptionMapper`.

### **QW-12: Add Missing @ApiOperation on REST Endpoints [DONE]**
* **Files:** All 8 REST resource classes in `arcclaw-app` + `arcclaw-onboarding`
* **Issue:** No OpenAPI annotations – Swagger UI shows bare endpoints without descriptions.
* **Fix:** Add `@Operation(summary=...)` from `org.eclipse.microprofile.openapi.annotations`.
